VirtuoX Player removes teaching controls and offers a more readable browser interface. It does not yet reproduce the complete stock FM-1 firmware. This comparison separates working browser features from the native integration still required.

Open-source firmware worth studying

Official FM1 Open

The manufacturer’s source is the closest foundation for preserving stock behavior: eight tracks, eight sample slots, four banks of 32 voices, track roles and MIDI channels, step recording, arpeggiator, effects and MIDI clock transport. The application has GPL-3.0 terms with an SDK linking exception; binary SDK components have separate terms. The linked workbench runs the upstream application separately from VirtuoX.

JIANT

A performance-focused alternative with six tracks, nine engines, song sections, effects and USB audio stems. Its interface and navigation are useful references for a hardware-friendly layout.

SLOOP

A Felucca-derived live groovebox: three synth tracks plus drums, song sections, parameter locks, MIDI learn and piano-roll MIDI import/export. Its pattern workflow is a useful reference for production lessons.

Felucca

A four-track, multi-engine synth with sequencing, songs, motion recording and a web editor. The author now describes slower feature development while continuing important fixes and maintaining the underlying BSP foundation.

The native development direction

For complete stock parity, retain the official synthesis, sequencing, sampler and MIDI core, then add a VirtuoX presentation layer and a separate Coach mode. Recreating those systems independently in JavaScript would not establish firmware compatibility. The current browser controls are a testable UI and learning prototype; the native port and full parity remain unfinished.

Learn expressive synthesis

Open Piano coach → Style library. M Dean-inspired studies progress through roots and octaves, syncopated bass, legato lead phrases, spacious voicings, climaxes and endings. Jarre-inspired studies explore pulses, arpeggios, space and sequences. Moog fundamentals cover glide, filtering, wheel and bend practice. Pick an automatic sound recipe or keep your own patch.

These are original studies, not artist transcriptions, official presets or endorsements. Moog-style sounds use a browser subtractive engine, not an emulation certified by Moog. Note and timing scoring works; filter gestures, bend curves and musical phrasing are currently practice instructions rather than automatically graded skills.
