FIRMWARE / RECOVERY / LOCAL FILE CHECK

One careful step
before you flash.

The browser demo is ready to explore. Native VirtuoX learning firmware is still in development. This page helps you find official firmware and identify a local file; it does not flash your instrument.

VirtuoX firmware: not released.Do not rename the browser source, a ZIP archive, or a JIANT firmware file to VirtuoX and install it. There is no tested VirtuoX .fwsc package in this repository.

Start with the firmware already on your FM-1.

  1. Back up what matters.Export patches, projects and samples using tools compatible with the firmware currently installed. A browser practice-history file is not a device backup.
  2. Read the target firmware’s migration instructions.JIANT instructs users coming from another custom firmware to return to official V15 first. That instruction belongs to JIANT; it is not a tested VirtuoX installation path.
  3. Use the official recovery source.M-VAVE’s workbench provides a return-to-original-V15 control. Recovery overwrites the four sound banks and restores the 128 factory voices; back up first.
  4. Use a data cable and stable power.Use desktop Chrome or Edge for the relevant Web MIDI/WebUSB tools. Close other applications using the MIDI port. Follow the updater’s directions and keep the connection stable.

External tools have their own firmware compatibility requirements and write to your instrument only after their own connection and confirmation process.

Choose a firmware file for a local check.

Select a file already on your computer. VirtuoX calculates its SHA-256 locally. Nothing is uploaded, and selecting a file does not connect to or write to your FM-1.

A match identifies that specific file. A mismatch can mean a different version or package; it is not permission to flash. The official workbench and manufacturer instructions remain the source for installation and recovery.

You will need to select the file again in the upstream updater.Browsers do not transfer your local file selection between independent websites. This page’s file checker is separate from the flashing tool.

Using JIANT?

JIANT’s installer includes its own firmware checks, backup flow and official recovery option. Use its instructions for JIANT installations. VirtuoX’s current browser prototype does not replace JIANT or implement its complete firmware features.

What must happen before “Install VirtuoX” exists?

  • A native C port of the lesson engine and color LCD interface.
  • Measured CPU, memory, polyphony and audio deadlines on a physical FM-1.
  • Tested settings and patch storage, migration, backup and recovery.
  • A versioned build with matching source, checksums, licenses and installation instructions.
  • Hardware testing of the update path, including unsuccessful and interrupted updates.
